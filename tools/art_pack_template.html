救援隊生圖清單

注音救援隊還缺的手繪圖，照優先順序排好。一條提示詞生一張圖，複製進 Gemini，生好了就在左邊蓋個腳印。

一格是一張圖已完成 0 / 0

生好之後

  1. 照清單上的檔名改名，例如 dog-1.jpg、card-fishing.png、words-3.jpg。
  2. 丟進專案的 img/raw/ 資料夾。
  3. 跟 Claude 說一聲，或自己跑 python tools/prep_images.py 再 npm run build。裁切、去背、切九宮格都會自動做。

Gemini 不一定照比例出圖，處理工具會從中間裁，所以重要的東西放中間就好。生出來有亂碼文字的圖，重生一次比較好。
