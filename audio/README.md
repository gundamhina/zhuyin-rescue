# 錄音檔

37 個注音符號的發音，來自教育部《國語注音符號手冊》電子書內附音檔。

- 來源：https://language.moe.gov.tw/001/Upload/files/site_content/M0001/juyin/html_ch/index.html
- 授權：創用 CC 姓名標示 4.0 國際（手冊聲明音檔與動畫檔採此授權，可自由利用）
- 原始檔名 F1–F37 依序對應 ㄅ…ㄙ（1–21）、ㄚ…ㄦ（22–34）、ㄧㄨㄩ（35–37），原檔留在 `raw/`

遊戲載入時先找 `audio/<符號>.mp3`，再找 `.wav`，都沒有才退回語音合成。
要換成自己錄的聲音，用同樣檔名蓋掉即可，一個符號一個檔。

## 結合韻（語音合成預先產生）

`ㄧㄚ.wav`、`ㄨㄛ.wav`… 這 21 個結合韻不是教育部錄音（手冊只有 37 個符號），是用微軟的臺灣中文神經網路語音「曉雨」（zh-TW-HsiaoYuNeural，Edge 瀏覽器「大聲朗讀」的聲音，透過 `edge-tts` 取得）唸代表字（鴨、窩、約…，`src/data.js` 的 `REP_CHAR_BASE`）預先產生的：語速放慢 40%，剪掉頭尾空白，音量調到跟官方錄音差不多，存成 24 kHz 單聲道 WAV。放成檔案是為了跟符號一樣開網頁就先載好，點了馬上有聲音，不用每次現場語音合成。

這些音檔的授權不像教育部錄音（CC BY 4.0）那麼清楚。要換成真人錄音，用同樣檔名蓋掉即可。

沒有 `ㄧㄞ.wav`：代表字「崖」語音合成唸成 ㄧㄚˊ，做不出對的音，所以 ㄧㄞ 仍然走語音合成（唸錯，待處理）。

## 聲調例字（語音合成預先產生）

`ㄇㄚ.wav`、`ㄇㄚˊ.wav`、`ㄇㄚˇ.wav`、`ㄇㄚˋ.wav`、`˙ㄇㄚ.wav`：注音表「聲調」那頁的例字（媽、麻、馬、罵、嗎），跟結合韻同一個聲音（曉雨，語速放慢 40%）、同樣處理。遊戲裡出現這幾個音節時也會用這些檔。
